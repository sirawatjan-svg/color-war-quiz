# สงครามสี (Color War Quiz)

เกมตอบคำถามแบบทั้งห้อง (2–4 ทีม, รองรับ 40 คน) แรงบันดาลใจจากคลิป "สงครามสี" บน Instagram:
สองสีสู้แย่งช่องบนกระดาน ถือช่องครบ 5 วิ = ล็อก (เกราะ 4) — ของเรา **นักเรียนตอบถูก 3 ข้อ = ปล่อยตัวละคร 1 ตัว**,
**ปล่อยครบ 3 ครั้ง = สกิลพิเศษ 1 ครั้ง**, ตอบถูกติดกัน 5 = โล่ล็อกเร็ว, 8 = แช่แข็งศัตรู, เพื่อน 3 คนปล่อยใน 3 วิ = คอมโบทีม

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `host.html` + `js/host.js` | จอครู: ตั้งค่า → ล็อบบี้ (QR) → คัดกรอง 3 ข้อ → แบ่งทีมอัตโนมัติ (snake draft, ครูสลับคนได้) → เกม → สรุปรางวัล |
| `index.html` + `js/landing.js` | หน้าแรก: ฉากหลังเป็นเกมจำลองที่เล่นเอง, แถลงการณ์, กรอบสื่อสาธิต, แท็บความสามารถ, หน้าจอจำลอง, แกลเลอรีตัวละคร |
| `play.html` + `js/player.js` | มือถือนักเรียน (QR ชี้มาที่นี่): เข้าห้อง → ตอบ → ปุ่ม Release / Skill → ผลส่วนตัว |
| `js/art.js` | วาดตัวละคร 4 สี (Ricochet / Splitter / Blaster / Surger) ใช้ทุกหน้า |
| `bank.html` + `js/bank.js` | คลังคำถาม (เก็บในเบราว์เซอร์เครื่องครู) โครงสร้างเดียวกับ quizjoy: ชุด → คำถาม A–D; นำเข้าแบบ `วิชา\|คำถาม\|A\|B\|C\|D\|เฉลย\|คำอธิบาย` และ CSV; ส่งออก CSV |
| `js/engine.js` | เอนจินกระดาน 64×36 ตัวละคร สกิล ล็อก/เกราะ กลไกตามทัน (รันใน Node ได้) |
| `js/fx.js` / `js/sfx.js` | ตัวเรนเดอร์ `FX.create()` (กระเบื้องแคช, bloom, หางแสง, ลำแสงตอนปล่อย, **ป้ายชื่อตัวใหญ่ ณ จุดปล่อย 3 วิ**, คัตอินสกิลเต็มจอ) / เสียงสังเคราะห์ + เพลงเร่งจังหวะ |
| `js/awards.js` | รางวัล 9 รายการ (คนละไม่เกิน 2) + ป้ายประจำตัวสำหรับคนที่ไม่ได้รางวัล |
| `js/net.js`, `js/config.js` | ซิงก์ผ่าน Firebase RTDB (`cw/{รหัสห้อง}`) หรือโหมดทดสอบในเครื่อง (`?local=1`) |
| `test/` | `power.js` พลังทาสีต่อฮีโร่ • `skillpower.js` ผลสกิล • `fair.js` ความยุติธรรมหลายรอบ • `sim.js` จำลองทั้งเกม |

## ทดสอบในเครื่อง

```bash
node dev-server.js
```
เปิด `http://localhost:8322/host.html?local=1` แล้วเปิดลิงก์นักเรียนจาก QR ในแท็บอื่นของเบราว์เซอร์เดียวกัน

## ดีไซน์

พื้นดำ + ลายสแกนไลน์ • ฟอนต์พิกเซล Silkscreen (อังกฤษ/ตัวเลข) + Kanit หนาผ่าแถบ `.sliced` (หัวข้อไทย — ฟอนต์พิกเซลไม่มีอักษรไทย)
• ปุ่มแคปซูลขาว • เขียวมะนาว `#d7f36a` ใช้กับสถานะ active เท่านั้น • สีสดอยู่ในภาพเกมเท่านั้น — โทเคนทั้งหมดอยู่ใน `style.css`
